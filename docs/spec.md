# かんたんAI親方 仕様書（第1版）

- 文書の種類：構想・機能仕様書（公開版）
- 作成日：2026-11-09
- 作成者：birdnnjjhiroselittle
- 例として扱う作業：**水栓（混合栓）の交換**

---

## 1. 概要

**かんたんAI親方**は、作業する人の目線のカメラ映像と声をAIがリアルタイムで見聞きし、

1. **施工方法**（次に何を、どの道具で、どう動かすか）
2. **事故防止の警告**（今それをすると危ない、を作業の前と最中に）

を、**声とAR表示**で教える「横に立つ親方」です。

最終的な形は **ARグラス**（またはカメラ付きイヤホン）で、両手を空けたまま教わることです。
最初はスマホのカメラとブラウザで動く試作から始めます。

### ひとことで

> 動画マニュアルは「見てから作業」。遠隔支援は「人が見ている間だけ」。
> かんたんAI親方は **「作業している、その瞬間に、AIがずっと見ている」**。

---

## 2. 背景と目的

- 建設・設備・内装の現場では、人手が足りず、ベテランのコツが若い人に伝わりにくくなっています。
- 家庭のDIYや補修でも、動画やマニュアルを見ながらの作業は、手が止まり、見落としや事故が起きやすくなります。
- ARグラスやスマートグラスで、現場作業を支える取り組みは多くの企業が進めています（遠隔支援、マニュアル表示など）。
  ただし多くは **「遠くの人が見る」** か **「決まった資料を表示する」** 形です。

かんたんAI親方の目的は、**AIが常に作業を見て、その場の状況に合わせて、施工方法と危険を先回りして伝える**ことです。

---

## 3. 利用者と利用場面

| 利用者 | 場面 | ほしいこと |
|---|---|---|
| 家庭のDIYをする人 | 水栓交換、棚の取り付け、クロス補修など | 失敗しない、ケガしない、無理な作業はプロに頼むと分かる |
| リフォーム・設備会社の新人 | 現場での施工 | ベテランがいなくても、正しい手順と注意点が分かる |
| 工務店・設備会社 | 新人教育、安全管理 | 教える人の時間を減らす、事故を減らす、施工の記録を残す |
| ベテラン職人 | ノウハウの伝承 | 自分のコツを、会社の「親方AI」に教え込む |

## 4. システムの構成

```
 ┌──────────── 作業する人 ────────────┐
 │ ARグラス / カメラ付きイヤホン / スマホ │
 │  カメラ・マイク・スピーカー・表示      │
 └──────────────┬─────────────────────┘
                │
   【第1層】端末の中のAI（速い・通信なし）
     手・工具・刃物・脚立・保護具・水滴・炎・蒸気を検出
     決まった危険ルールで即座に警告（目標 0.3秒以内）
                │
   【第2層】クラウドの視覚言語AI（賢い・数秒）
     手順の理解、施工の良し悪し、ステップ完了の判定、
     質問への回答、手順書の作成
                │
   【第3層】知識（ナレッジ）
     メーカーの施工説明書、法律・ルール、
     会社のマニュアル、ベテランのコツ（業務版）
                │
   【第4層】人へのつなぎ（エスカレーション）
     AIが判断できない・危険が大きいときは、
     プロへの依頼、または遠隔の熟練者（遠隔支援サービス）へ切り替え
```

- **命に関わる警告は第1層で出す**：通信が切れても、クラウドが遅くても止まらないようにします。
- **施工の判断は第2層で出す**：数秒かかってもよい内容（やり方の修正、次のステップの案内）です。
- 試作（スマホ版）では第1層を作らず、第2層だけで数秒ごとに確認します。

## 5. 機能仕様

### F1. 作業の受付と「やっていいか」の判定（法律・安全の門番）

- 利用者が作業を選ぶか、声で伝える。
- 次の作業は **AIに聞く前に、端末のルールで止める**（日本の場合）：

| 作業 | 理由 | 親方の対応 |
|---|---|---|
| 屋内配線、コンセント・スイッチの交換や増設 | 電気工事士の資格が必要（電気工事士法） | 手順を教えず、電気工事店をすすめる |
| ガス管・ガス機器・給湯器の接続 | 資格者の仕事 | 手順を教えず、ガス会社・専門業者をすすめる |
| 給水管・給湯管の延長、移設、壁内・床下の配管工事 | 水道局が指定する工事事業者の仕事 | 手順を教えず、指定工事店をすすめる |
| 古い建物の壁・天井・床材の解体や切削 | 石綿（アスベスト）の可能性 | 事前調査をすすめる |
| 柱・梁・耐力壁を切る・抜く | 建物が弱くなる | 建築士・工務店への相談をすすめる |
| 屋根・高所の作業 | 転落事故が多い | 原則プロに任せるよう強くすすめる |

- 判定は3段階：**✅ DIYでできる / ⚠ 注意すればできる / 🛑 プロに任せる**
- 🛑 の作業では、見守りモードを始められない（プロに頼むための準備だけを案内する）。

### F2. 手順書の自動作成

- 作業内容、製品の型番、現場の写真から、次を作る：
  - 必要な保護具、道具、材料
  - 起きやすい事故
  - **1ステップ1動作**の手順。各ステップに「やり方」「危険と防ぎ方」「できた状態（カメラで確認できる形）」
- メーカーの施工説明書がある場合は、それを優先する（第3層）。

### F3. 作業前チェック

- 保護具（手袋、保護メガネなど）を着けているかをカメラで確認する。
- 作業場所の片付け、足元、照明を確認する。
- 例の水栓交換では **「水が止まっているか」を必ず確認してから** 次へ進む。

### F4. リアルタイム見守り

- カメラの映像を常に見て、次の4つを判定する：

| レベル | 意味 | 表示 | 声 | 振動 |
|---|---|---|---|---|
| 🛑 危険 | 今すぐ止めるべき | 画面が赤く点滅、大きな文字 | 他の音声を止めて、短く命令形で | 強く3回 |
| ⚠ 注意 | このまま続けると危ない | 黄色の枠と文字 | 短く | 弱く1回 |
| ✅ 安全 | 問題なし | 緑の小さな表示 | なし | なし |
| 👀 見守れていない | 暗い・ブレ・手元が映っていない | **灰色の枠と「見守れていません」** | 「手元を映してください」 | なし |

- **見守れていないときに「安全」と表示しない**（フェイルセーフ）。
- やり方の修正（例：「シールテープの巻く向きが逆です」）は、同じ内容を何度も繰り返さない。
- ステップの「できた状態」になったら、「できたようです。次へ進みますか？」と聞く。

### F5. AR表示（グラス版）

- 実物に重ねて表示するもの：
  - **対象の部品に名札**（例：「止水栓」「偏心管」「ナット」）
  - **回す方向の矢印**と、回す量の目安
  - **水平・垂直のガイド線**、取付ピッチ（2本の管の間隔）の測定
  - **危険エリアの赤い輪郭**（刃の進む先、熱いお湯の出口など）
  - 次に使う道具のアイコン
- 表示は最小限にする（視界をふさいで事故を起こさないため）。危険の表示を最優先する。

### F6. 声での対話

- 「次」「戻る」「止めて」「もう一回」は端末の中で処理する（速く、料金がかからない）。
- それ以外の質問（例：「このナット固いけどどうする？」）は、今の映像と一緒にAIに聞き、2〜3文の話し言葉で答える。

### F7. 記録と報告（業務版・本人が選んだときだけ）

- ステップごとの施工写真、完了時刻、出した警告を記録し、施工報告書・日報の下書きを作る。
- 家庭版は初期設定で **何も保存しない**。

### F8. プロ・熟練者へのつなぎ

- 次のときは作業を止め、プロへの依頼か、遠隔の熟練者への切り替えをすすめる：
  - AIが判断できない状態が続く
  - F1の「プロに任せる」条件に当てはまると分かった（例：作業中に配管の腐食を見つけた）
  - 利用者がケガをした（医療の判断はせず、手当てと受診をすすめる）

### F9. メーカー説明書の読み込み（PDF → 手順・見本・確認の基準）

- 利用者が製品のメーカー説明書（PDF）を渡すか、型番から説明書を探す。
- AIが説明書を読み、次に使う：
  1. **手順書（F2）**：説明書の手順・数値（例：シールテープの巻き数、締め付けの目安、取付寸法）と注意事項を最優先する。一般的な知識と違うときは説明書に従う。
  2. **根拠の表示**：各ステップに「📄 説明書 ○ページ」と該当部分の要約を表示し、利用者が原文を確かめられるようにする。
  3. **確認の基準（F11）**：「できた状態」を説明書の記載から作る。
- 説明書が別の製品のものだと分かったら、作業の前に知らせる。
- 業務版では、メーカーの説明書に会社のマニュアル・ベテランのコツを重ねる（第3層）。

### F10. 見本（簡単な映像）と重ね表示

- 説明書の図や文章から、各ステップの **手の動きだけを見せる短いループのアニメーション** を作る（回す向き、巻く向き、締める順番など、間違えやすい点を太い矢印で強調）。
- 表示の方法は3つから選ぶ：
  - **小窓**：画面やグラスの隅に見本を出す
  - **重ねる**：カメラ映像（グラスでは実物）の上に、半透明の見本を重ねる
  - **投影**（将来）：小型プロジェクタで、作業する部品の上に直接、矢印や見本を映す
- 声の説明を添える。「見本」「お手本」と言えば、もう一度見せる。
- 次のステップの見本は先に作っておき、待たせない。

### F11. 施工の確認（「これで良い？」）

- 作業の途中で、利用者がボタンか声（「これで良い？」「合ってる？」）で確認を頼む。
- AIは今の映像を、そのステップの「できた状態」と説明書の記載に照らして判定する：

| 判定 | 伝えること |
|---|---|
| ⭕ 大丈夫 | 何を見て大丈夫と判断したか（例：「テープが時計回りに巻かれていて、先端のネジ山が1山残っています」） |
| 🔧 直すところがある | どこが違うかと、直し方（例：「巻く向きが逆です。いったんはがして、ネジを締める向きに巻き直してください」） |
| 👀 判断できない | どう映せば判断できるか（例：「ネジの先端を正面から、もう少し近くで映してください」） |

- **見えていない部分を推測で「大丈夫」と言わない**（迷うときは「判断できない」）。
- 業務版では、確認した映像と判定を施工記録（F7）に残せる。

## 6. 例：水栓（混合栓）の交換

### 6.1 対象

- **壁付きの混合栓**（キッチン・浴室で、壁から2本の管が出ていて、湯と水を混ぜる水栓）を、同じ形の新しい混合栓に交換する。
- 台付き（流し台に穴があいて取り付ける形）の違いは 6.6 に書く。

### 6.2 作業前の判定（F1）

| 確認すること | 親方の判断 |
|---|---|
| 既存の水栓を外して、同じ場所に新しい水栓を付けるだけか | ✅ DIYでできる範囲（配管そのものには手を加えない） |
| 配管の位置を変える・延ばす必要があるか | 🛑 指定工事店に依頼 |
| 止水栓・元栓が閉まるか | 閉まらなければ 🛑 プロに依頼 |
| 新しい水栓の取付ピッチ・形が既存と合うか | 合わなければ製品を選び直す |
| マンションか | ⚠ 水漏れが階下に広がるので特に注意。管理規約も確認 |
| 自治体（水道局）のルール | 地域で扱いが違う場合があるので確認をすすめる |

### 6.3 保護具・道具・材料

- 保護具：作業用手袋（流し台の下の板金で手を切らないため）、必要に応じて保護メガネ
- 道具：モンキーレンチ（2本あると便利）、水栓レンチ、ドライバー、古い歯ブラシ、バケツ、タオル・雑巾、懐中電灯
- 材料：新しい混合栓（付属のパッキン・偏心管・座金）、シールテープ

### 6.4 起きやすい事故と失敗

1. **水を止め忘れて水が噴き出す**（部屋や階下の水浸し）
2. **熱いお湯でやけど**（給湯側の止め忘れ、試運転で急に熱湯）
3. **固いナットに無理な力をかけ、壁の中の配管を傷める・ねじ切る**（大きな水漏れ）
4. **シールテープの巻く向き・量の間違い**で、取り付け後に少しずつ漏れる
5. **偏心管を締めた後に逆向きに戻して位置を合わせ**、ネジのすき間から漏れる
6. **濡れた床で、近くのコンセントや電気製品に触れる**
7. 流し台の下や浴室での無理な姿勢による腰痛、板金の角での切り傷

### 6.5 手順と、親方の見守り

| # | ステップ | やり方 | AR表示 | カメラで確認すること（できた状態） | 🛑 / ⚠ の警告の例 |
|---|---|---|---|---|---|
| 1 | 型番と形を確かめる | 古い水栓の形（壁付き）、2本の管の間隔を確認し、新しい水栓と合うか比べる | 2本の管の中心に印と、間隔の測定値 | 間隔を測り、新しい水栓の説明書の範囲に入っている | ⚠「取付ピッチが合いません。製品を確認してください」 |
| 2 | 給湯器の温度を下げる・止める | 給湯器のリモコンで電源を切るか、温度を下げる | リモコンに名札 | リモコンの表示が消えている、または低温 | — |
| 3 | 水を止める | 止水栓（ない場合は水道メーター横の元栓）を右に回して閉める。湯側も閉める | 止水栓に名札と「右回し」の矢印 | **蛇口を開けても水もお湯も出ない** | 🛑（水が出ているのにナットに手をかけた）「水が止まっていません。作業を止めて」 |
| 4 | 残った水を抜く | 蛇口を開けたまま、下にバケツとタオルを置く | 水受けを置く場所 | バケツとタオルが置いてある | ⚠「床が濡れています。近くのコンセントに注意」 |
| 5 | 古い水栓を外す | 本体を左右の管につないでいるナットを、モンキーレンチで左に回して外す | ナットに名札と「左回し」の矢印 | 本体が外れて、偏心管が見えている | ⚠（ナットが固く、管ごと回っている）「管ごと回っています。力をかけないで。もう1本のレンチで管を押さえて」／🛑（ハンマーでたたこうとした）「たたかないで。配管が壊れます」 |
| 6 | 偏心管を外す | 壁から出ている偏心管を左に回して外す | 偏心管に名札と矢印 | 壁の中の給水口が見えている | 🛑（壁の中の管がぐらつく・回る）「壁の中の管が動いています。作業を止めてプロに相談を」 |
| 7 | 掃除とネジ山の確認 | 古いシールテープや汚れを歯ブラシで落とす。ネジ山が欠けていないか、さびていないか見る | 確認する場所を丸で囲む | ネジ山がきれいに見えている | 🛑（ひどいさび・割れを検出）「配管が傷んでいます。ここからはプロに任せましょう」 |
| 8 | シールテープを巻く | 新しい偏心管のネジに、先端を1山残して、**ネジを締める向き（先端から見て時計回り）に** 7〜8周巻く（製品の説明書を優先） | **巻く向きの矢印**、先端1山の目印 | 巻く向きが正しく、先端が1山残っている | ⚠「巻く向きが逆です。巻き直してください」 |
| 9 | 偏心管を取り付ける | 右に回してねじ込む。2本の高さをそろえ、間隔を説明書の範囲に合わせる。**位置合わせは締める方向で行い、逆に戻さない** | 水平線、2本の間隔の測定値 | 2本が同じ高さ、間隔が範囲内 | ⚠「戻す方向に回すと漏れの原因になります。締める方向で合わせてください」／⚠「高さがそろっていません」 |
| 10 | 座金と本体を付ける | 座金（カバー）を付け、パッキンを入れて本体を当て、左右のナットを少しずつ交互に締める。レンチには布を当てて傷を防ぐ | 本体の水平線、締める順番の番号 | 本体が水平で、ナットが両方締まっている | ⚠「本体が傾いています」／⚠「パッキンが入っていません」 |
| 11 | 水を通して漏れを確かめる | 止水栓を少しずつ開ける。つなぎ目を乾いたティッシュで触り、濡れないか確かめる | つなぎ目を丸で囲む | ティッシュが濡れない、水滴が見えない | ⚠（水滴を検出）「ここから漏れています。止水栓を閉めて、締め直しを」 |
| 12 | 動作とお湯の温度を確かめる | 給湯器を戻し、**最初は低い温度から**湯と水の切り替え、温度調節を確かめる（サーモ式は説明書どおりに温度を合わせる） | 吐水口に「熱湯注意」 | 湯と水が切り替わり、温度が調節できる | 🛑（吐水口の下に手、高温設定）「熱いお湯が出ます。手をどけて」 |
| 13 | 片付けと記録 | 古い水栓を自治体のルールで処分。新しい水栓の型番と交換日を記録 | — | 道具が片付いている | — |

### 6.6 説明書・見本・「これで良い？」の使われ方（ステップ8 シールテープの例）

1. 利用者が、新しい混合栓の説明書（PDF）を最初に渡しておく。手順書のステップ8に「📄 説明書 ○ページ：シールテープは○周巻く」と、説明書の記載が表示される。
2. ステップ8に進むと、小窓に **見本アニメーション**：偏心管のネジ部分の線画に、テープが **先端から見て時計回り** に巻かれていく動きと、オレンジの矢印、先端1山の印。声で「ネジを締める向きに、先端を1山残して巻きます」。
3. グラス版では、実物の偏心管の上に **巻く向きの矢印を重ねて** 表示する。
4. 巻き終わったら、利用者が「これで良い？」と聞く。
5. AIが映像を確かめて答える：
   - ⭕「時計回りに巻かれていて、先端の1山も残っています。巻き数も説明書どおりに見えます。次に進めます」
   - 🔧「巻く向きが逆です。このままだと、ねじ込むときにテープがめくれて漏れる原因になります。はがして巻き直してください」
   - 👀「ネジの先端が影になっています。もう少し明るい所で、横から映してください」

### 6.7 台付き混合栓の場合の違い

- 流し台の下にもぐって、給水・給湯のホースと固定ナットを外す作業になる。
- 親方の追加の見守り：懐中電灯で手元を明るくするよう案内、板金での切り傷、湯と水のホースの付け間違い（色と表示の確認）、無理な姿勢。
- 食洗機の分岐金具がある場合は、付け直しの手順を追加する。

### 6.8 作業を止めてプロに任せる条件

- 止水栓・元栓が閉まらない、または閉めても水が止まらない
- 壁や床の中の管がぐらつく、回る、さびや割れがある
- 配管の延長・移設が必要と分かった
- 1時間以上進まない、利用者が不安を感じた

## 7. 安全設計の原則

1. **AIは見落とすことがある**ことを、使う前と画面に必ず示す。最後に判断するのは作業する人。
2. **見えていないのに「安全」と言わない**（見守れていない状態を表示する）。
3. **命に関わる警告は通信がなくても出す**（第1層）。
4. **法律で資格が必要な作業は教えない**（F1の門番）。
5. **迷ったら止める側に倒す**：危険かどうか分からないときは「注意」を出す。
6. 表示は最小限にして、視界をふさがない。

## 8. 非機能の要件

| 項目 | 目標 |
|---|---|
| 危険の警告までの時間 | 第1層：0.3秒以内（目標）／第2層：数秒 |
| 通信がないとき | 第1層の警告と、保存済みの手順は使える |
| プライバシー | 家庭版は映像を保存しない。AIに送るのは判定に必要な1コマだけ。結果（言葉）だけを使う |
| 業務版の記録 | 会社と作業者が同意した範囲だけ保存。顔や個人情報はぼかす |
| 対応機器 | ARグラス、カメラ付きイヤホン、スマホ（試作） |
| 言葉 | 日本語から。やさしい日本語、外国人の作業者向けの多言語に広げる |

## 9. 業務での使い方（企業向け）

- **会社の親方AI**：メーカーの施工説明書と会社のマニュアルに加え、ベテラン職人が作業しながら話したコツを取り込み、その会社専用の親方にする。
- **新人教育**：新人が一人で現場に出ても、親方AIが見守る。熟練者は、AIが「判断できない」と言ったときだけ遠隔でつなぐ（遠隔支援サービスとの組み合わせ）。
- **安全管理**：作業前の危険予知（KY）を、その日の作業内容から自動で作る。出た警告を集計して、事故が起きやすい作業を見つける。
- **施工記録**：ステップごとの写真から、施工報告書の下書きを作る。

## 10. 進め方（ロードマップ）

1. **スマホ版の試作**：第2層だけで、数秒ごとに確認。水栓交換などの家庭DIYで試す。
2. **第1層の追加**：端末の中で、工具・刃物・手・保護具・水滴・炎を検出するモデルを入れ、警告を速くする。
3. **ARグラス版**：両手を空けたまま、声と重ね表示で教わる。
4. **業務版**：工務店・設備会社と実証。会社のマニュアルとベテランのコツの取り込み、記録と報告。
