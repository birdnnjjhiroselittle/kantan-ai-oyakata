# かんたんAI親方

**作業している、その瞬間に、AIがずっと見ている。**

ARグラス（カメラ付きイヤホン・スマホ）の映像と声をAIがリアルタイムで見聞きし、
**施工方法**と**事故防止の警告**を、声とAR表示で教える「横に立つ親方」の構想です。

- 🛑 **事故防止**：「水が止まっていません」「管ごと回っています。力をかけないで」と、危ない瞬間に止める
- 🛠 **施工方法**：次の動作、回す方向、巻く向きを、実物に重ねて表示
- ⚖ **法律の門番**：電気工事・ガス・配管工事など資格が必要な作業は教えず、プロにつなぐ
- 📄 **メーカー説明書を読む**：PDFの説明書から、手順・数値・注意を優先して教え、動きは簡単な見本アニメーションで見せる（小窓／映像に重ねる／投影）
- ✅ **「これで良い？」**：シールテープの巻き方など、途中の出来ばえをその場で確認
- 👀 **見えていないのに「安全」と言わない**

## 対象

- 家庭のDIY・住まいの補修・内装工事
- リフォーム会社・設備会社・工務店の新人教育と安全管理

## 公開の目的

ARグラスやAIで現場の作業を支えたいと考える人や企業は少なくありません。
この構想を自由に参考にしてもらい、**現場の事故とケガを減らす**ことにつなげたいと考えて公開しています。
